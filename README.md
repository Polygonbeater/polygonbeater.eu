# Polygon Beater — 3D Graphic Studio

Official web repository for **Polygon Beater**, a 3D graphic studio specializing in product visualization, Web3D interactive applications, and high-precision modeling. Live website: [polygonbeater.eu](https://polygonbeater.eu).

---

## 🛠️ Tech Stack & Features
* **Frontend:** Clean HTML5 & modern CSS3 (CSS Grid, Flexbox, Custom Properties)
* **Scripting:** Vanilla JavaScript (ES6) — dynamic language switching (CZ/EN), 3D stage interaction, smooth scrolling
* **Typography:** Big Shoulders Display, IBM Plex Sans, IBM Plex Mono
* **Form Handler:** Web3Forms API with Honeypot anti-spam protection
* **SEO & Metadata:** Open Graph protocols, Twitter Cards, `sitemap.xml`, and `robots.txt`
* **i18n:** Client-side localization with `localStorage` preference persistence
